# iCloud Drive 歌单同步（0.9.3）

当前采用 Apple 系统文件夹授权与 iCloud Drive，不使用 CloudKit 专属容器。适用于本项目目前的 Personal Team 真机签名：无需自行搭服务器，也无需为了同步先注册 CloudKit。

## 开启

1. 两端安装 0.9.3 或更新版本（旧版 Mac 无法发送数据）。Mac 与 iPhone 的系统设置均登录同一个 Apple 账号，并打开 iCloud Drive。
2. 点击 Ting 顶栏的云朵按钮，选择「选择 iCloud 文件夹」。
3. 在 iCloud 云盘中新建或选择 `Ting` 文件夹，两台设备必须选择同一个文件夹，不能选「我的 iPhone」或仅存于 Mac 的文件夹。
4. 首次自动合并原有本机歌单与收藏。之后编辑会自动保存，前台每 30 秒尝试交换，回到前台、恢复网络也会触发；可点击「立即同步」。
5. 在歌单页的「本机」分类查看跨设备的混合歌单。该分类表示 Ting 内部管理的歌单，数据始终有本机副本。

当前范围为 Ting 收藏、本机混合歌单的名称、创建/删除、歌曲元数据、来源和顺序。网易云 / QQ 自身的云歌单仍由音乐平台同步；账号分别登录。最近播放、播放进度、设置及音频文件不在本版同步范围内。

## 没有同步过来时

- 检查实际运行版本：仅下载新版安装包不会更新「应用程序」里的旧版 Mac 应用。
- 两端都要点击云朵，各自授权同一个 iCloud 云盘 / Ting 文件夹。只在 iPhone 开启时，Mac 原有数据不会自动上传。
- 网易云 / QQ 歌单在两端分别登录同一平台账号，再打开歌单页对应平台；它们不通过 Ting iCloud 复制。
- Ting 的收藏在「收藏」页，混合歌单在「歌单 → 本机」页。两端前台点「立即同步」，等待 iCloud 文件实际到达。

## 状态和限制

「已与同步文件夹交换」表示已读写系统提供的文件夹，不代表另一台设备已收到，也不代表 iCloud 上传完成。离线时先保留修改，iCloud 在网络与系统调度允许时传输；后台持续运行不作保证。若系统未把所选位置标为 iCloud，界面会提示确认目录。

停用只撤销 Ting 保存的文件夹授权，不删除本机或云端数据。重新选目录会将本机的同步歌单与新目录合并，不会自动删除原目录。目录移动或授权过期时需重新选择。开发签名本身仍有七天有效期，同步不改变安装签名规则。

## 合并与数据保护

- 原 `ting.playlists` 保留作升级前副本，新本机快照与待确认操作原子写入 `ting.library-sync.v1`。原生层先保存后确认，失败的操作保留并幂等重试。
- 收藏复用同一合并协议，使用保留集合 ID `9007199254740991`，不出现在普通歌单管理里；新歌单不会分配此 ID。两端应同时升级至 0.9.3。旧 `ting.favorites` 保留作备份，通过原子迁移标记仅导入一次，避免取消收藏后重启又导回旧数据。
- Rust 负责字段级 Lamport 版本合并。不同设备各自新增的歌曲都保留；删除用墓碑记录，旧副本不能把删除歌曲带回来。明确重新加入同一首歌曲允许恢复。
- 同时更改同一名称、同一歌曲的存在状态或同一歌单的顺序，按逻辑版本和随机设备 ID 确定唯一结果。并发排序取其中一个完整顺序，再保留另一端新增歌曲；不声称同时满足互相矛盾的排序。
- `Ting-Sync-v1/device-<随机设备ID>.json` 为每台设备独立的合并快照，不让两台设备写同一个文件；系统文件协调、原子替换、未变内容不重复写入。
- 目录书签仅存在本机原生状态中；同步字段白名单不包含 Cookie、手机号、验证码、访问令牌、临时播放地址或本地文件句柄。歌单内容以 JSON 保存，隐私保护沿用用户 iCloud 账号与系统设置，不是 Ting 自定义端到端加密。
- 损坏、新版本、不合规格、超限或符号链接文件会阻止该轮交换并显示原因，不用空歌单覆盖。当前最多 2,000 个歌单（包括墓碑），每单 20,000 个曲目记录，每个设备快照 16 MiB、一次读取总计 32 MiB。
- 本机数据库设备标识与前端已确认标识不一致时停止同步，保留歌单，避免数据目录丢失后误把空库当成最新结果。

## 验证边界

Rust 用例覆盖双端独立新增、删除后合并旧副本、并发改名/排序、明确重新加歌、同 ID 不同平台、幂等重试、无效输入与本机损坏保护。浏览器用例覆盖升级迁移、目录取消、接收变更、停用、同步中继续编辑、失败重启恢复和窄屏布局。macOS 原生测试实际运行书签解析、文件协调和读写，不是只 mock 文件 API。iOS 原生部分须通过 arm64 编译与真机文件夹选择验证；云端两端传输结果以实际联调为准。

Apple 文档：[目录选择与持久授权](https://developer.apple.com/documentation/uikit/providing-access-to-directories)、[Personal Team 签名限制](https://developer.apple.com/support/compare-memberships/)。
