# 2026-09-18 实现质量复查

范围：系统媒体、播放和队列、手机歌词交互、下载发布、本机/文件夹同步、登录凭据恢复及发布流水线。先检查可复現行为，再修复；没有访问或导出真实账号凭据。

| 严重性 | 发现 | 本轮处理 |
| --- | --- | --- |
| P1 | Apple 原生字典与 WebView 实际音频会话不一致，清空 Web 元信息导致封面/标题回归丢失 | 移除孤立 Apple 原生桥，恢复真实 Web Media Session |
| P1 | 空 Audio 初始化时一次性注册，WebKit listener 尚未创建会丢失系统动作 | 在资源就绪、播放及前台恢复后重申动作 |
| P2 | NotAllowedError 后重试有声音但系统元信息被清空 | 保留选中曲目，并在其它失败后的重试恢复元信息 |
| P2 | 连续系统切歌被暂时清空的状态吞掉，或将缓冲误判为用户暂停 | 在加载期间保留目标歌曲和播放意图，尊重等待期间的暂停 |
| P1 | Windows 0.61 回调签名错误、Linux共享连接回调不满足Sync，导致目标平台无法编译 | 修正回调类型和锁边界，增加目标平台CI |
| P2 | 封面缓存失败阻断整条SMTC/MPRIS更新 | 封面单独降级，保留文本和控制信息 |
| P2 | Linux会话总线断开后永久失效 | 下次更新重建后端并发布当前快照 |
| P2 | 下载降级复制存在检查后覆盖竞态及半成品残留 | create_new原子认领，失败清理本次文件；并发/故障注入测试 |
| P2 | 非Apple平台收藏同步待办无人消费并持续增长 | 全平台本机确认，非Apple固定exchange:false；旧积压分批恢复 |
| P2 | 无效旧QQ凭据阻止重新扫码登录 | 无效载入按未登录恢复，新扫码使用匿名客户端，保留有效会话 |
| P2 | Windows多命令CI可能忽略前序失败，Linux测试缺ffmpeg | 使用失败即停止的shell，并补测试依赖 |

验证证据包括模拟WebKit生命周期、真实HTML音频回调、播放拒绝恢复、连续切歌/暂停竞态、下载并发不覆盖、同步积压恢复和fixture凭据。桌面专项额外用真实Windows依赖做目标类型检查，并用真实dbus-daemon验证断开重连、元信息及命令；其Tauri窗口/事件出口使用替身，因此不等同Linux桌面UI实测。

手机歌词展开/收起使用可取消过渡；覆盖中途关闭和减少动态效果。版本保持0.9.5，以90503标识本轮构建。90502的Apple原生桥已由真机反馈否定，不能将其孤立测试当作系统控制中心验收。

尚需实机验收：iOS 90503控制中心按钮和切歌，Windows/Linux桌面媒体面板，以及锁屏后长时间连续切歌。CI/模型测试不能代替这些检查。
