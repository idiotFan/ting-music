# WebDAV / 坚果云歌单同步（1.0.0）

WebDAV 与 [iCloud 同步](ICLOUD-SYNC.md) 使用同一套本机快照、待确认队列和字段级合并协议，只把传输换成 WebDAV。Mac、Windows、Linux、iPhone、Android 都可使用；同一时间只启用一种同步方式。

## 坚果云

1. 在坚果云网页版打开「账户信息 → 安全选项 → 第三方应用管理」，添加应用，复制生成的应用密码。不要填写坚果云登录密码。
2. 点击 Ting 顶栏的云朵按钮；Mac / iPhone 先切换到「坚果云 / WebDAV」。
3. 服务选「坚果云」，账号填写坚果云登录邮箱或手机号，密码填写第三方应用密码，文件夹默认 `Ting`。
4. 点「测试并连接」。Ting 会确认账号，并在需要时创建 `Ting/Ting-Sync-v1/`。每台设备填写同一个账号和文件夹。

服务器地址固定为 `https://dav.jianguoyun.com/dav/`。坚果云免费版每 30 分钟最多 600 次请求（付费版 1500 次），单次列目录最多 750 项。Ting 只列一个只含设备快照的目录，前台空闲时每 60 秒检查一次；快照未变（ETag 相同）时只发 1 次 PROPFIND，不下载也不上传。出错后检查间隔逐次加倍，最长 16 分钟。

## 其他 WebDAV 服务

服务选「其他 WebDAV」，填写服务器给出的完整地址（例如 Nextcloud 的 `https://example.com/remote.php/dav/files/<用户名>/`）。只接受 `https://`；仅局域网 NAS（localhost、私有 IP、`.local`）允许 `http://`。地址不能包含账号、参数或 `#`。Ting 不跟随重定向，服务器发生跳转时请填写跳转后的地址。

## 数据与凭据

- 云端结构与 iCloud 相同：`<文件夹>/Ting-Sync-v1/device-<随机设备ID>.json`，每台设备只写自己的文件，其他设备的文件只读取。
- 同步内容只有 Ting 收藏和本机混合歌单（名称、歌曲元数据、来源、顺序和删除墓碑），不含音乐平台登录信息、本地文件路径或音频。
- WebDAV 密码只由 Rust 层读写系统凭据存储：macOS / iOS 钥匙串、Windows 凭据管理器、Linux Secret Service、Android Keystore。它不进入 WebView、localStorage、本机同步快照或云端文件，状态接口只返回服务器主机名、账号和文件夹。停用同步会删除保存的密码，但不删除本机歌单或云端文件。
- 内容以 JSON 明文存放在你的 WebDAV 网盘中，隐私保护依赖服务商；Ting 没有额外的端到端加密。

## 安全顺序

1. 本机编辑先原子写入本机状态，再确认前端待同步队列。
2. `PROPFIND Depth: 1` 列出快照目录（不存在时逐级 `MKCOL` 创建），列表上限 4 MiB。
3. 只下载 ETag 变化的设备快照：单个 16 MiB、一轮合计 32 MiB；损坏、新版本或不合规格的文件会中止本轮，显示原因，不覆盖任何本机或云端数据。
4. 合并结果连同已合并快照的 ETag 一起原子写入本机，然后才 `PUT` 本设备快照；内容摘要未变则不上传。
5. 网络、认证、限流（429 / 503）、空间不足等失败只显示提示；本机修改保留，下次自动重试。

## 验证边界

Rust 测试使用本地 WebDAV 服务器覆盖认证失败、目录创建、两台设备双向合并、ETag 跳过、上传失败后重试、密码错误或丢失、云端损坏文件不覆盖，以及密码不出现在本机状态、返回值和云端文件中；XML 解析覆盖坚果云前缀格式、默认命名空间和实体转义。浏览器测试覆盖坚果云表单、错误提示、更换账号、停用和 Apple 上的 iCloud / WebDAV 切换。真实坚果云账号的联调以实际使用为准。
