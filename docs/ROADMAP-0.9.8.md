# 0.9.8 规划

2026-09-23 定稿，全部条目纳入 0.9.8。按阶段推进，每个阶段结束都能构建安装、跑全量回归。公开版本号在用户明确要求发布 0.9.8 前保持 0.9.7。

工作量：S 约一天，M 两到三天，L 一周上下。

## 风险

- 歌手 / 专辑接口两平台都要新接，QQ 侧签名与字段变化最多，先做网易云再做 QQ。
- 已下载文件与在线歌曲的关联只对本应用下载、带 `.json` 旁注的文件可靠；其他来源的文件只按标签匹配，不自动合并。
- 阶段 4 的托盘、迷你播放器、悬浮歌词都是新窗口，Windows / Linux 需要真机验证。
