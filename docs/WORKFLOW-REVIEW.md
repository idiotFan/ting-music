# 0.9.1 工作流复审

复审范围：Logo / 返回首页、搜索、播放、歌单浏览和刷新、登录方式切换、退出登录，以及手机竖屏、横屏、键盘和弹窗。

| 发现的问题 | 修正 |
| --- | --- |
| Logo 链接保留 WebKit 点击高亮，重复点击重写当前页面 | 改为 44px 按钮，去除触控临时高亮；同页操作不更新 DOM、不重新请求、不改变滚动 |
| 手机常驻顶部内容占近半屏 | 内容移至上方，播放器与导航固定在底部；横屏左右分栏，搜索聚焦时给键盘腾出空间 |
| 页面共用滚动位置，新歌单从中段打开 | 按页面保存与恢复滚动位置，新歌单从顶部开始 |
| 退出请求完成后关闭了另一平台面板 | 根据来源和当前流程判断是否更新面板；切回正在退出的账号后也刷新旧资料 |
| 已有本机歌单导致中断的云歌单加载被误判完成 | 独立记录加载完成状态，忽略旧响应；提供明确的刷新入口 |
| 手机只有扫码方式 | 网易云默认手机号验证码，可切换扫码；iOS 扫码页提供原文件系统分享，QQ/微信相册识别受平台限制 |
| 关闭登录后迟到响应可能激活旧会话 | 前后端均检查取消代次；短信号码绑定、发送冷却、会话超时，敏感输入不持久化 |

验证：67 项浏览器用例通过，包含二维码最终截图解码与像素一致性；35 项 Rust 离线用例、网易云真实 QR / 音质只读回归通过。iOS arm64 原生编译检查通过。旧主分支的 CI 已通过，按用户要求重跑的 workflow 为 35193342240；新提交发布时由 CI 再检查。

手机布局覆盖 320×568、393×852、568×320、852×393、820×1180，以及软键盘缩小视口。393px 竖屏主列表可滚动区域约 542px，底部播放器约 145px，导航 56px。iPad / Android 的浏览器模拟不能替代真机验收。

短信验证码登录的测试使用模拟接口，没有向真实号码发送短信；真人验证码确认和平台安全验证仍需用户在设备上操作。系统分享接收原 PNG 文件，不对码点重新生成或有损编码；目标 App 是否接受相册登录码、目标分享活动如何保存图片，需要对应 App 实测，不能以 PNG 解码成功替代授权验收。后台播放、锁屏控制、QQ / 微信官方一键授权尚未实现。
