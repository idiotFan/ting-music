# 0.9.6 动画与界面稳定性

本轮保持原有紧凑布局和桌面双击／手机轻点播放方式，统一状态切换，并优先消除内容重建造成的闪烁。公开版本为 **0.9.6**，iOS 内部构建号为 **90601**；后续普通修复继续沿用该公开版本。

## 交互变化

| 场景 | 行为 |
| --- | --- |
| 搜索、歌单、收藏、本地、队列切换 | 导航标记平滑移动，内容轻微位移淡入；重复点当前页面不重建内容、不重置滚动 |
| 歌单刷新和编辑后的刷新 | 保留已有卡片、歌曲行及封面；结果到达后只更新有变化的内容；请求失败保留已有内容 |
| 搜索新关键词或平台 | 保留上一批结果直至新结果到达；新请求失败后不允许把另一查询的分页混入旧结果 |
| 切歌 | 下一张封面完成下载与解码后淡入；快速切换只接收最新请求，连续淡入不强制跳到中间帧 |
| 歌词加载 | 保留旧歌词的画面并暂时禁止点击，等当前歌曲歌词就绪后替换；旧请求不能覆盖新歌词 |
| 歌词展开 | 桌面在右侧展开并协调原生窗口宽度；手机整页展开，支持尚未结束时立即反向关闭／打开 |
| 歌词跟随、切换音质 | 高亮通过透明度与小幅水平位移过渡，不改变行高；同歌切音质保留阅读位置 |
| 账号、主题、歌单操作、同步设置 | 统一进入／退出过渡；快速重新打开不会被旧的关闭动画关掉；保留原生焦点约束 |
| 手机输入 | 输入开始时结束弹窗位移动画，交给键盘避让，避免输入框被动画推到键盘下方 |
| 登录二维码 | 原图解码校验不变；等外层动画结束后再显示和对齐，保持二维码尺寸与实际像素 |
| 主题 | 同明暗配色平滑插值；跨深浅色同步切换文字和背景，避免中间态文字失去对比度 |
| 播放按钮、收藏、提示消息 | 短促反馈；音量和播放进度更新不会反复替换图标或封面 |

## 实现约束

- `src/motion.ts` 管理可取消的有限时长动画，结束后释放效果与引用。弹窗仍使用原生 `showModal()` / `close()`，保留焦点恢复和已有忙碌保护。
- `src/cover.ts` 在屏幕外解码图片，最多显示两层封面及等待中的最新一张，失败后允许重新请求相同 URL。
- `src/lyrics.ts` 将原生窗口调整串行执行；过期的过渡结果不能改变当前开合状态。
- 不逐行启动成百上千个动画，不对播放进度持续重绘，不使用全局 `transition: all`，不引入新的运行时依赖。
- 遵循系统 `prefers-reduced-motion`，运行中开启「减少动态效果」也会结束当前动画；所有功能继续可用。

```sh
npm run build

npx playwright test
npm run check:release
python3 -B scripts/scan-secrets.py --history
```

`tests/motion.spec.ts` 覆盖稳定 DOM、刷新时保留内容、连续导航、延迟及乱序图片／歌词、弹窗反向切换和动态效果偏好的运行时变化。既有测试继续覆盖双账号登录、二维码最终像素及解码、歌单增删排序、播放队列、音质、系统媒体、离线文件、同步和手机键盘／缩放。

浏览器回归使用模拟平台接口，并不代表真实网易云／QQ 服务或所有原生设备均已验收。原生构建和装机状态以对应交付说明为准。
